# ASL Interpreter

Spells words in real time!

## Features

- Recognizes ASL hand signs
- Works in real time with a webcam
- Shows the predicted letter on screen

## Installation

```bash
git clone https://github.com/Akshata717/asl-interpreter
cd asl-interpreter
pip install -r requirements.txt
```

## Usage

```bash
python predict.py
```

Press `q` to quit.
